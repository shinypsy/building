B. 특정 기능에 대해 상세 플렌이 나오면 plan.md 파일을 doc폴더 아래 반드시 기록한다.
C. 코드 스니팻도 포함 시켜야한다.
D. 기능별 명칭 사용 기록 한다
E. 오프셋 패이징 대신 인풋 패이징 을 지원 해야한다.
F. plan.md 파일명으로 기록
G. 소스파일을 읽고 실제 코드 베이스를 기반으로 계획을 작성해야 함.
a. plan.md 파일에 담기는 내용
    i. 접근 방식 상세 설명, 코드 구조 상세 설명
    ii. 코드 스니펫
    iii. 파일 경로
    iv. 트레이드오프

3. 주석달기(Artifact)
A. artfact 파일에 업데이트하면 plan.md 파일에 업데이트 해아함.

4. 구현 및 실행
A. 전부 구현해줘 또는 전체 실행해줘 라는 요구가 있을 때 실행한다.

C. 모든 작업과 단계가 완료될 때까지 멈추지 마라
D. any 나 unknown 타입을 사용하지 마라

G. 당일 최종본을 Git에 upload할지를 나에게 물어보고 upload를 진행한다.
